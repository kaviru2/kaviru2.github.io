# kaviru2.github.io

Minimal personal academic website for Kaviru Hapuarachchi.

To add a profile photo, put `photo.jpg` (square, ~400px) in the repo root and replace the photo comment in `index.html` with `<img class="photo" src="photo.jpg" alt="Kaviru Hapuarachchi">`.

## Local preview

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

The site is plain HTML and CSS with no build step or external dependencies.
